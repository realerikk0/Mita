# Unpublished upstream history

This directory preserves source material inherited from the Jan/Menlo upstream
project for attribution and historical reference. It is deliberately outside
`docs/src`, `docs/public`, and every Cloudflare Pages build input.

Nothing under this directory is a current Biyan product page, support promise,
privacy statement, download instruction, or runtime capability. Do not publish
it, add it to the Nextra page map, sitemap, search index, or release artifact.
