# Biyan Desktop

Biyan (彼岩) brings cloud and OpenAI-compatible model providers into one desktop workspace. Conversation data and app settings are stored locally; request content is processed by the provider selected for that chat.

<Callout type="warning">
  Biyan does not download or run local language models. The former local engines, model Hub, RAG, embeddings, and vector database are retired.
</Callout>

## Data boundaries

- Biyan keeps threads, settings, provider configuration, and migration state in its local data folder.
- API keys are credentials for third-party services. Never include them in screenshots or support reports.
- Messages, attachments, and MCP results included in a request leave the device and are processed under the selected provider's terms.
- Biyan never silently switches a retired local-model conversation to a paid remote model.
