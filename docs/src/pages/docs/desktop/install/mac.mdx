# Install Biyan on macOS

1. Download the current signed macOS installer from the [Biyan website](https://biyan.ai/).
2. Open the `.dmg` file and drag **Biyan** to **Applications**.
3. Launch Biyan and approve the normal macOS confirmation for a downloaded application.
4. Add a cloud provider under **Settings → Model Providers**.

Biyan runs on supported Intel and Apple Silicon Macs. It does not install a local model engine or download a default language model.

## Data

The default application data location is:

```text
~/Library/Application Support/Biyan/
```

An upgrade may copy supported data from an earlier location. The old source and retired model/RAG files remain untouched until you explicitly clean them up. See [Data and Migration](/docs/desktop/data-folder).

## Uninstall

Quit Biyan and remove it from **Applications**. This does not delete your Biyan or legacy data.

<Callout type="warning">
  Delete a data directory only after backing it up and verifying its exact path. Application data removal is permanent and is not required to uninstall the app.
</Callout>
