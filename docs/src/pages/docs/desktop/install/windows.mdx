# Install Biyan on Windows

1. Download the current signed Windows installer from the [Biyan website](https://biyan.ai/).
2. Run the installer and follow the Windows prompts.
3. Launch **Biyan**.
4. Add a cloud provider under **Settings → Model Providers**.

Biyan supports current maintained Windows releases supported by its Tauri runtime. It does not install GPU runtimes, llama.cpp, or a default local model.

## Data

The default application data location is:

```text
%APPDATA%\Biyan\
```

During migration, legacy folders are treated as read-only sources and are not deleted automatically. See [Data and Migration](/docs/desktop/data-folder).

## Uninstall

Use **Settings → Apps → Installed apps**, find **Biyan**, and choose **Uninstall**. Removing the application does not delete Biyan or legacy user data.

<Callout type="warning">
  Do not manually delete `%APPDATA%` folders until migration has completed and important conversations have been verified or backed up.
</Callout>
