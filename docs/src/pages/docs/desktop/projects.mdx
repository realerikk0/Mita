# Projects

Projects group related conversations under a shared name and optional Assistant. They are an organizational feature, not a retrieval system.

## Create a project

1. Choose **New Project** in the sidebar.
2. Give the project a clear name.
3. Optionally assign an [Assistant](/docs/desktop/assistants).
4. Start one or more conversations inside the project.

## Files

Attach a document to the message that needs it. Biyan either uses the selected provider's native file interface or extracts the document's complete text locally for that request.

Biyan does not chunk project files, generate embeddings, store vectors, or automatically retrieve passages. Retired project knowledge-base data remains in the old source folder until the user explicitly removes it; see [Data and Migration](/docs/desktop/data-folder).
