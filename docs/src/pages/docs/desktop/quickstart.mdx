# Quickstart

<Steps>

### Install Biyan

Get a signed installer from the [Biyan website](https://biyan.ai/) and follow the guide for [macOS](/docs/desktop/install/mac), [Windows](/docs/desktop/install/windows), or [Linux](/docs/desktop/install/linux).

### Add a model provider

Open **Settings → Model Providers**, choose a provider, and enter the credentials issued by that provider. For a compatible custom service, use the OpenAI-compatible provider and set its base URL.

### Select a model

Create a chat, open the model selector, and choose a model from the configured provider. Biyan does not select a paid remote model automatically.

### Send a message

Type a message or attach a supported image/document. Attachment behavior depends on the selected provider's capabilities; review [Images and Documents](/docs/desktop/file-upload) first.

</Steps>

<Callout type="warning">
  Biyan is cloud/remote-only. It does not download a default model or start a local inference engine.
</Callout>

Next: configure [MCP tools](/docs/desktop/mcp), create an [Assistant](/docs/desktop/assistants), or organize work in [Projects](/docs/desktop/projects).
