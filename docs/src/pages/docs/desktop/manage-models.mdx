# Provider Models

Biyan lists models exposed by each configured remote provider. Open **Settings → Model Providers**, choose a provider, and configure its credentials and endpoint.

## Add a model

- Use **Refresh Models** when the provider supports model discovery.
- If a compatible provider does not expose a model-list endpoint, add the exact model ID supplied by that provider.
- Set capabilities such as image, file, and tool calling only when confirmed by the provider documentation.

## Remove a model

Remove a custom model entry from its provider configuration. Provider-discovered entries may reappear after refresh and must instead be controlled through that provider.

## Retired local models

<Callout type="warning">
  Biyan has no local model Hub, GGUF/MLX import, local model downloader, or local engine settings. Existing downloaded files are not loaded and are not deleted automatically.
</Callout>

When an old conversation points to a retired local model, its history remains readable. Select a configured remote model before continuing; Biyan never chooses one automatically.
