# Settings

Open **Settings** from the lower-left application menu.

## Model Providers

Configure cloud providers, credentials, base URLs, available models, and confirmed model capabilities. Biyan does not include local engine, local model import, model download, or Hugging Face mirror settings.

Store credentials only in their provider fields. Never paste API keys into a chat, screenshot, support email, or MCP configuration that does not require them.

## Data folder

Use **Settings → General → Data Folder** to open or relocate Biyan data. Relocation copies into staging, validates the result, and switches only after success; the source remains in place. See [Biyan Data and Migration](/docs/desktop/data-folder).

## API gateway

Configure the loopback host, port, and local gateway API key. The gateway proxies configured remote providers and never starts a local model runtime.

## MCP servers

Add MCP commands and environment variables, grant tools narrowly, and review server output before enabling automatic tool execution. See [MCP](/docs/desktop/mcp).

## Network and proxy

An HTTPS proxy affects provider and integration traffic. Ignoring TLS certificate errors weakens connection security and should be used only for a trusted managed proxy.

## Factory reset

<Callout type="warning">
  Factory reset permanently removes data from the selected Biyan data folder. Export or back up conversations first. Legacy Mita/Silence/Jan-derived folders and retired model/RAG data are not silently deleted by this action.
</Callout>

## Diagnostics

Migration and application diagnostics should contain error codes and redacted paths. Before sending anything to [help@biyan.ai](mailto:help@biyan.ai), remove provider keys, private prompts, document contents, and full local paths.
