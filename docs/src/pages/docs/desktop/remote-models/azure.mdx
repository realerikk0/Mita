# Azure OpenAI

1. Create or select an Azure OpenAI resource and deployment.
2. Open **Settings → Model Providers → Azure OpenAI**.
3. Enter the resource endpoint, API key, API version, and deployment name exactly as configured in Azure.
4. Save and select the deployment-backed model in a chat.

Azure deployment names are not always the same as base model names. Region, quota, content filtering, retention, capabilities, and billing follow your Azure configuration.

Biyan sends request content directly to the configured Azure endpoint.
