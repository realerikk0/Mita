# OpenAI and Compatible APIs

1. Create an API key with the remote service you intend to use.
2. Open **Settings → Model Providers → OpenAI** (or **OpenAI-compatible**).
3. Enter the API key. For a compatible service, enter its documented base URL.
4. Refresh the model list or add the exact remote model ID when discovery is unavailable.
5. Save, select the model in a chat, and send a small test message.

Enable image, native-file, or tool-calling capabilities only when the selected API and model support them. Biyan sends requests directly to the provider endpoint you configure and does not rewrite Hugging Face URLs to an application mirror.

<Callout type="warning">
  Requests are processed by the configured remote service and may incur charges. Biyan never selects a paid model automatically.
</Callout>
