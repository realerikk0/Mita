# Mistral AI

1. Create an API key in the [Mistral AI Console](https://console.mistral.ai/).
2. Open **Settings → Model Providers → Mistral AI**.
3. Enter the key and refresh models.
4. Select a remote model in a chat.

Use model IDs and capability flags confirmed by Mistral AI. Availability, context limits, tools, attachments, data handling, and billing remain under the provider's policies.

Biyan does not download Mistral model weights or start local inference.
