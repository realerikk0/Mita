# Groq

1. Create a key in the [Groq Console](https://console.groq.com/keys).
2. Open **Settings → Model Providers → Groq**.
3. Enter the key and refresh the model list.
4. Select a model in a chat.

If discovery does not show a required model, add the exact ID currently documented by Groq. Model availability, capabilities, limits, data handling, and billing are controlled by Groq.

Biyan uses Groq as a remote provider; it does not download the underlying model to your device.
