# OpenRouter

1. Create an API key in [OpenRouter](https://openrouter.ai/keys).
2. Open **Settings → Model Providers → OpenRouter**.
3. Enter the key and refresh models.
4. Select a model ID and send a small test request.

OpenRouter may route to different upstream providers according to your account and request settings. Review the selected model/provider routing, data policy, limits, and price before sending sensitive or large content.

Biyan never chooses a paid OpenRouter model automatically.
