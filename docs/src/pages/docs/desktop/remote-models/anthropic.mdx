# Anthropic

1. Create an API key in the [Anthropic Console](https://console.anthropic.com/).
2. Open **Settings → Model Providers → Anthropic**.
3. Enter the key and refresh available models.
4. Select an Anthropic model in a chat.

Model availability, attachments, tool calling, context limits, retention, and billing are controlled by Anthropic. Confirm current capabilities in Anthropic's documentation before enabling them in Biyan.

Biyan sends messages, selected conversation context, and any native attachment/tool content required for the request directly to Anthropic.
