# Google Gemini

1. Obtain an API key or approved endpoint credentials from the Google service you use.
2. Open **Settings → Model Providers → Google**.
3. Enter the credentials and endpoint settings required by that service.
4. Refresh models and select one in a chat.

Use the exact model ID returned or documented by Google. Image, native-file, tool-calling, context, regional availability, and billing rules vary by API and model; enable only confirmed capabilities.

Request content is processed by the configured Google service.
