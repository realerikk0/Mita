# MCP Servers

Open **Settings → MCP Servers** to add, edit, start, stop, or remove Model Context Protocol servers.

## Configuration fields

- **Name:** a unique display name.
- **Command:** an executable available to Biyan.
- **Arguments:** one argument per entry, in execution order.
- **Environment variables:** only values required by that server. Do not reuse a model Provider key unless the server explicitly requires it and is trusted.
- **Tool permissions:** enable the smallest set needed.

## Smart tool routing

When many servers are connected, Smart MCP tool routing can select a smaller relevant server set before loading tools. An optional dedicated remote routing model may be configured. If routing fails or yields no usable tools, the documented fallback path widens the tool list.

<Callout type="warning">
  A server runs with the permissions of your user account. Review its package/source and command before starting it, especially when using package runners that can fetch code from the internet.
</Callout>

The managed built-in integration appears as **Biyan Web Research**. See [MCP](/docs/desktop/mcp) for migration and safety notes.
