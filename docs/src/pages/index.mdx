# Biyan Documentation

Biyan (彼岩) is a desktop AI client for cloud and OpenAI-compatible model providers. Conversations and settings stay in the Biyan data folder; prompts, attachments, and tool results included in a request are processed by the provider you select.

## Start here

- [Install and configure Biyan](/docs/desktop/quickstart)
- [Connect a cloud provider](/docs/desktop/remote-models/openai)
- [Send images and documents](/docs/desktop/file-upload)
- [Migrate data from an earlier release](/docs/desktop/data-folder)
- [Configure MCP tools](/docs/desktop/mcp)

Biyan does not download or run local language models. Local model engines, the model Hub, RAG, embeddings, and vector databases are not part of the supported product.

For help, email [help@biyan.ai](mailto:help@biyan.ai).
