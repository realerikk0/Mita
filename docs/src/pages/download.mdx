# Get Biyan

Use the [Biyan website](https://biyan.ai/) for current signed desktop installers and release information.

Existing users should update through the in-app updater. The supported release train migrates users through A, B, and C; a later installer also contains all earlier migration steps for users who have been offline.

Before installing, review the [data migration guide](/docs/desktop/data-folder). Biyan never silently deletes old application data, downloaded local models, or retired RAG/vector files.
