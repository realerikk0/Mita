# Support

Email [help@biyan.ai](mailto:help@biyan.ai) for product support.

Include the Biyan version, operating system, the failing action, and a short redacted error message. Do not send API keys, full logs, private prompts, complete local paths, or original documents unless a trusted support reply asks for a specific redacted diagnostic.
